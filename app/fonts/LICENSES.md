# Tipografías

- Cormorant Garamond, Copyright 2015 The Cormorant Project Authors.
- Allura, Copyright 2010 The Allura Project Authors.

Ambas se distribuyen bajo la SIL Open Font License 1.1.

Fuentes: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond y https://github.com/google/fonts/tree/main/ofl/allura
